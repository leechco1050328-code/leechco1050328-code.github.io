# えあわせ探検帳 サポート

iPhone用パズルゲーム「えあわせ探検帳」の遊び方とお問い合わせ窓口です。

## ピースの置き方

「あそぶ」から好きな絵と盤面サイズを選びます。下の置き場からピースを指で運び、正しいマスに6割以上重ねて指を離すと、ぴたりとはまります。絵柄が分かりづらいときは「みほん」で完成した絵を確認できます。

## 途中から遊ぶには

探検帳の「つづき」を押すと、置いたピースを残したまま再開できます。遊んだ記録は、このiPhoneに保存されます。

遊び方のご質問や不具合のご連絡は、[サポート窓口にメールする](mailto:r3ach.app@gmail.com)からお送りください。宛先は **r3ach.app@gmail.com** です。
